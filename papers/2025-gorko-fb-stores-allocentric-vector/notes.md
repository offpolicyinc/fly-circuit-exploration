# Gorko 2025: the fan-shaped body stores a vector (dissertation)

Model: PFL1 combines a head-direction input (bridge) with a fan-shaped-body input and outputs a vector in egocentric Cartesian coordinates. Fitting Δ7 and PFL1 recordings gives a "stored direction" that is stable across trials within a fly and differs between flies.

Chapter 3, imaging FC1, Δ7 and PFL1 together: FC1 calcium tracks head direction (its PFNa input), not the stored direction. FB2B calcium likewise does not encode it. Abstract: "I rule out a simple mechanism where the vector is encoded by the calcium activity of the presynaptic neurons."

FB2B axons show a sinusoidal cAMP pattern (Gflamp2) whose phase correlates with heading and is in phase with the FC1 calcium bump; FC1 is FB2B's largest axonal input and appears to express sNPF. "Whether and how this second messenger signaling contributes to the stored direction input to PFL1 remain open questions."

Discussion hypothesis: the stored direction is a sinusoidal pattern of FB2B→PFL1 synaptic weights, with the cAMP as an eligibility trace and a separate signal gating plasticity.

Bearing on this repository: the stored vector is absent from calcium in the cells that should carry it (evidence against activity storage in that circuit), and a heading-locked cAMP signal sits where a synaptic write would happen. It is not an observation of a stored vector in cAMP; earlier text here that said so was wrong and has been corrected.
