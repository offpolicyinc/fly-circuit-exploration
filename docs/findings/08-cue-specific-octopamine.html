Finding 8 of 8 · a prediction from a published mechanism

The octopamine teaching signal reaches some cue channels and not others

The compass learns which landmark goes with which heading by adjusting the synapses from ring neurons onto compass cells. A 2025 preprint found the teaching signal: EL neurons read the compass and release octopamine onto the ring-neuron terminals. The wiring shows EL output is not spread evenly. It concentrates on four ring classes and barely touches ER4m, the single strongest ring input to the compass, which instead receives feedback straight from the compass cells. Prediction: silencing EL should break learning for some cue types and spare others.

Background

Ring neurons
~26 classes of inhibitory ER neurons bring cues into the compass: visual features (ER4d, ER4m, ER2), wind (ER1, ER3w), and internal states such as sleep drive (ER5). Each class inhibits compass cells at synapses whose strengths are learned so that a cue maps onto the right heading (Kim 2019; Fisher 2019).
The coincidence problem
To adjust an inhibitory synapse you need the terminal to know what the postsynaptic compass cell is doing. Plitt et al. 2025 showed EL neurons solve this: they read the compass bump and release octopamine onto ring-neuron terminals; without them the compass fails to anchor to a new visual scene.
Dopamine, separately
ExR2 dopamine says when to learn (during turns; Fisher 2022). EL octopamine says which terminals.

Each EL cell is tuned to one compass position (55–70 % of its EPG input from one bridge glomerulus), so the 18 ELs tile the heading circle, matching Plitt's EL bump. Full table for all 26 classes in er_subtype_motif.csv.

Why it matters

  • Two coincidence mechanisms, not one. ER4d, ER3p, ER3d, ER2_c get heading information through EL octopamine; ER4m and ER6 get it as direct EPG synapses. Different molecular rules likely apply, and the "which terminals" signal Plitt found is not universal.
  • A concrete, cheap prediction. EL silencing should abolish anchoring to cues carried by ER4d-type channels and spare cues carried by ER4m. Plitt's assay used a visual scene; splitting the cue by ring class turns one result into a map.
  • Learning may be state-gated. ER5, the sleep-drive ring class, is EL's largest single input (10,073 synapses). If ER5 suppresses EL, compass learning would be switched off with sleep pressure, which connects to the rest-state dynamics Flores-Valle 2025 saw in the fan-shaped body.

What would settle it

  • Repeat Plitt's remapping assay with EL silenced, using cues that engage ER4d versus ER4m drivers; predict a class-specific deficit.
  • Record EL during sleep deprivation or ER5 activation; predict suppression.
  • Localise octopamine receptors on ring terminals by class; predict enrichment on the EL-targeted classes.
